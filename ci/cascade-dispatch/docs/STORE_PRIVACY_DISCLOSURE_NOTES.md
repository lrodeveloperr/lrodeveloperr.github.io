# Store privacy disclosure notes

- Gameplay progress: device-local.
- No Cascade gameplay account/backend.
- Advertising: Google AdMob in free mode only, after the applicable UMP privacy state permits requests; no banner on Home or during active gameplay.
- Ad request configuration: non-personalized (`npa=1`) and restricted-data-processing signal (`rdp=1`); publisher first-party identifier disabled in the AdMob runtime adapter.
- Purchase: one lifetime non-consumable product, `cascade_dispatch_unlimited_forever`; Apple/Google process payments and return entitlement status.
- Exact App Store Privacy / Google Play Data safety answers must be rechecked against the native SDK versions actually shipped.
