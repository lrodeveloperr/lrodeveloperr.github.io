Email support

How to play

  1. Read the network: one signal passes through ten relays and branches to Modules A, B, and C.
  2. Inspect all three modules. Compare their textual telemetry; one contains the root anomaly.
  3. Select one module and commit once. The deterministic engine certifies the outcome before presentation begins.

There is no decision timer. Accuracy, not speed, protects Lumen City.

Attempt rules

  • You start with five free attempts.
  • Only an incorrect scored response consumes one.
  • Success, practice, tutorials, technical recovery, and leaving before a response cost nothing.
  • After the first free loss from a full balance, all five free attempts reset together 24 hours later. They do not refill one by one or stack.
  • Purchases are disabled in this technical beta.

Accessibility and display

Open Settings to choose light, dark, or system appearance; reduced motion; larger text; higher contrast; haptics; audio, music, and effects; and language. The adult route also includes paid-attempt confirmation for a possible later commerce release; it cannot initiate a purchase in this beta and is absent from the protected route. The beta targets portrait and both landscape directions. If content clips at a safe area, cutout, 200% text, or a 320–412 logical-width viewport, please include that detail in your report.

Recover from a problem

  1. Leave the app in the foreground briefly, then relaunch. An uncommitted active signal should resume without a net attempt charge.
  2. Check that you are testing the intended build number.
  3. If the app reports a device-time change, correct the device date and time. The free-attempt reset remains paused while the clock is inconsistent.
  4. If only local progress is corrupt, Settings → Reset local progress provides a confirmation before removal.
  5. Do not reset app data to troubleshoot paid value in a future monetized build. Contact support first. The current beta has no paid value.

Report a defect

Email lrodeveloperr@gmail.com with:

  • Android/iOS version and device model;
  • Cascade Dispatch build/version number;
  • the screen and exact actions that led to the issue;
  • whether the app was offline, rotated, backgrounded, or using accessibility features;
  • a screenshot or short screen recording if safe.

Please never include passwords, payment-card data, identity documents, private store receipts, or unrelated personal information.

Privacy requests and security

Use the same email for privacy rights or a responsible security report. Put Privacy request or Security report in the subject. Do not publish an exploitable purchase-integrity issue before LRO Developer has had a reasonable chance to assess it.
